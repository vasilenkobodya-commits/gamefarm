# Мій Агрохолдинг — гра-тайкун для Android

Розвивай господарство з однієї грядки до агрохолдингу всеукраїнського рівня:
садж овочі → сад і виноградник → будуй теплиці з кліматконтролем → наймай персонал →
модернізуй техніку та вихід на експорт.

Гра — це один HTML/JS файл (`app/src/main/assets/index.html`), загорнутий у мінімальний
Kotlin WebView-застосунок, і працює повністю офлайн (прогрес зберігається в
localStorage самого WebView).

## Як отримати .apk (без Android Studio на комп'ютері)

Проєкт вже містить GitHub Actions workflow (`.github/workflows/build.yml`), який
компілює APK у хмарі — так само, як ти вже робив для компаньйон-застосунку agrosad.fun.

1. Створи новий репозиторій на GitHub (публічний або приватний).
2. Заливай туди весь вміст цієї папки:
   ```
   git init
   git add .
   git commit -m "Перший коміт"
   git branch -M main
   git remote add origin https://github.com/ТВІЙ_НІК/agroholding-game.git
   git push -u origin main
   ```
3. Відкрий вкладку **Actions** у репозиторії — збірка запуститься автоматично.
4. Коли workflow позеленіє, відкрий цей run → розділ **Artifacts** внизу сторінки →
   завантаж `agroholding-debug-apk.zip`, розпакуй — усередині `app-debug.apk`.
5. Перекинь `.apk` на телефон і встанови (Android попросить дозволити встановлення
   з "невідомого джерела" — це нормально для debug-збірки поза Google Play).

Це debug-збірка (без підпису релізним ключем) — для особистого використання й
тестування підходить без обмежень. Якщо захочеш публікувати в Google Play, знадобиться
підписаний release-білд — про це можна поговорити окремо.

## Локальна збірка (якщо Android Studio таки з'явиться)

Відкрий папку проєкту в Android Studio → дай Gradle синхронізуватись → Run.

## Структура гри (де що правити)

Уся логіка й баланс гри — в одному файлі `app/src/main/assets/index.html`:

- `CROPS` — культури (ціна насіння, час росту, ціна продажу, на якому рівні відкривається)
- `TIERS` — рівні розвитку господарства (присадибна ділянка → агрохолдинг)
- `WORKER_TYPES` — типи найманих працівників
- `UPGRADES` — одноразові модернізації (датчики ESP32, зрошення, трактор, склад, експорт)

Можна міняти цифри балансу прямо там, без перезбірки Kotlin-коду — досить лише
переробити APK через Actions (workflow вже налаштований).

## Наступні ідеї для розвитку гри

- Прив'язати реальні дані сортів/культур з agrosad.fun
- Додати кілька регіонів/локацій замість одного поля ділянок
- Ринкові коливання цін (як у Startup Company) замість фіксованих
- Досягнення й щоденні бонуси
